Final Year Project IoT + Cloud

Smart Fire Detection & Alert System

Designed and built a complete real-time fire detection and early warning system as my final year project. The system continuously monitors the environment for signs of fire and triggers both local and remote alerts.

Hardware Components

  • ESP32 – Main microcontroller with Wi-Fi
  • MQ-2 – Smoke & gas detection sensor
  • DHT11 – Temperature & humidity sensor
  • Buzzer – Local audible alarm

How It Works

  • Sensors continuously read smoke, gas and temperature levels
  • ESP32 processes the data in real time
  • When thresholds are exceeded, the buzzer activates
  • Alerts can be sent via Wi-Fi to a monitoring system

What I Accomplished

I designed the circuit, selected and integrated the sensors (MQ-2 + DHT11), programmed the ESP32 using the Arduino IDE, calibrated detection thresholds, implemented the buzzer alarm logic, and successfully demonstrated a working prototype capable of early fire detection with both local and remote notification capabilities.
