Smart Fire Detection & Alert System

Designed and built a complete real-time fire detection and early warning system as my final year project. The system continuously monitors the environment for signs of fire and triggers both a local alarm and remote mobile alerts.

Hardware Components

  • ESP32 – Main microcontroller with Wi-Fi
  • MQ-2 – Smoke & gas detection sensor
  • DHT11 – Temperature & humidity sensor
  • Buzzer – Local audible alarm

Software & Cloud Architecture

  • ESP32 streams smoke, gas and temperature readings to a Flask API
  • Flask relays readings into a Firebase Realtime Database
  • A React Native (Expo) app subscribes to Firebase for live updates
  • FCM pushes remote alerts the moment a threshold is crossed

What I Accomplished

I designed the circuit, selected and integrated the sensors (MQ-2 + DHT11), programmed the ESP32, built a Flask backend to receive sensor data and relay it to a Firebase Realtime Database, developed a companion React Native (Expo) app for live monitoring, wired up FCM push notifications for remote alerts, and implemented the local buzzer as a hardware-level failsafe that fires even if the network connection drops. Successfully built, demonstrated, and defended as my final year project.
