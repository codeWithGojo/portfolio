Smart Fire Detection & Alert System

Problem

Fire needs to be caught in seconds, not minutes — and someone away from the room still needs to know the moment it starts.

What We Built

An ESP32 rig (MQ-2 + DHT11 + buzzer) streaming live readings through a Flask API into Firebase, with a React Native app and FCM push alerts. Local buzzer failsafe even without network.

Impact

Built, demonstrated, and successfully defended as a complete final year project — circuit to cloud to mobile, working end to end.

ESP32 · MQ-2 · DHT11 · Flask · Firebase · React Native · FCM
